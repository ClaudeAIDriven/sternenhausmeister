# StarScrubber
Cozy-Koop-Spiel (3D, bis 4+ Spieler): Putze den Nachthimmel, bring Sternbilder zum Leuchten.
Engine: Godot 4.3. Start: Ordner in Godot öffnen und F5, oder `godot --path .`.
Tests: `tools/run_tests.sh`. Aufgaben: `TASKS/INDEX.md`. Mitmachen: `CONTRIBUTING.md`. Steuerung: WASD, Maus, Leertaste, linke Maustaste/E putzen.
